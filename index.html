How I work with AI

Coding agents are part of my daily workflow, not an experiment. What makes them safe to use is the review layer around them.

  • Tooling. Claude Code every day, with my own skills, prompt templates and context handoffs between sessions. MCP servers connect the agents to real systems — task tracker, repositories, databases — so they work from facts instead of guesses.
  • In product. Claude SDK integrated into applications: multi-step agents with typed tools, OCR and transcription, under a redaction policy that strips personal data before anything leaves the system.
  • Validation. Generated code and documentation are checked against the actual repository before they are merged. An agent once created task dependencies that did not exist; catching it before it blocked the team is the reason every workflow I build has explicit checkpoints and automated tests.
  • Transfer. I documented that workflow and trained new team members on it, including someone starting from zero.
